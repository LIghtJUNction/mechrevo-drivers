# 界面设计

当前实现是原生 Rust / egui 桌面界面，入口见 [desktop.rs](crates/gui/src/desktop.rs)、[appearance.rs](crates/gui/src/appearance.rs) 和 [main.rs](crates/gui/src/main.rs)。产品范围见 [PRODUCT.md](PRODUCT.md)。这里记录界面的实现约定，硬件兼容与测试结论分别以对应验收记录为准。

## 视觉方向与参考

用户明确要求“磨砂、极简、留白、艺术字”，以石墨深色为主，不使用蓝色。细节集中在材质边缘、字体比例、短交互反馈与真实读数上。旧的 Cyber-HUD 和固定侧栏布局已不再作为设计方向。

本轮可核查的参考来自设计师本人公开的网站：

- [Rauno Freiberg · Designing Depth](https://rauno.me/craft/depth)：参考其通过前后层次、背景虚化与边界处理建立深度的思路。
- [Emil Kowalski](https://emilkowal.ski/)：参考其公开交互作品对界面反馈与细节的处理。

用户所说的 X 上设计师作品是参考方向；上述链接是实际查阅的公开来源，不表示已经查看受限的 X 帖子，也不表示照搬某位设计师的完整界面。

## 材质与颜色

页面使用应用内部绘制的柔和背景：固定的暖色与鼠尾草色弥散场叠加少量静态颗粒，纹理按主题缓存。面板在其上使用半透明填充、细边、上沿反光和柔和阴影，形成磨砂材质的观感。实现不截取桌面，也不调用操作系统的桌面背景模糊；背景与颗粒不逐帧变化，不依赖传感器输入。

| 用途 | 石墨主题 | 浅色主题 |
| --- | --- | --- |
| 基础页面背景 | `#171818` | `#F1F0E9` |
| 磨砂面板填充 | `rgba(40,40,38,172/255)` | `rgba(255,254,248,180/255)` |
| 主文字 | `#F1EFE7` | `#252723` |
| 次要文字 | `#A4A59D` | `#64695B` |
| CPU 曲线／确认反馈 | `#A7C08C` | `#45692C` |
| GPU 曲线／等待反馈 | `#DDBB7C` | `#89641F` |
| 错误反馈 | `#ED9A8C` | `#9A2E22` |

默认使用石墨主题，也可选择浅色或跟随系统。绿与琥珀用于读数区分与必要反馈；页面不以大面积高饱和色装饰运行状态。磨砂面板圆角为 24，内边距通常为 28，可用宽度不足 380 时为 18。数值均为逻辑单位，实际颜色包含背景与透明层的混合，以源码为准。

## 字体与留白

[字体资产目录](crates/gui/assets/fonts/README.md)随程序嵌入 Cormorant Garamond Italic 和 Manrope，并保留各自的 SIL Open Font License 1.1。运行时不下载字体。

- Cormorant Garamond Italic 用于 `Control.`、`Observe.`、`Discover.` 这一个英文页标题，以倾斜衬线字形成视觉重心。宽屏字号 60，副标题 15；窄屏标题按可用宽度缩小，副标题为 17。
- Manrope 用于拉丁界面文字和读数；温度主读数字号 56，单位为 18。两份可变字体通过字体坐标显式设置 `wght` 轴：Cormorant 为 400，Manrope 为 450。中文继续由操作系统字体提供器补全，艺术标题字体不承担中文字形。
- 正文与按钮默认 14、次要文字 12；文字缩放范围为 80–160%。控件最小交互高度 36，常规控件圆角 8。
- 主内容宽度最多 1000，居中排布；窗口宽度至少为 900 时外边距为 40，更窄时为 16。留白用于区分标题、主要读数和操作区，不增加空白的装饰模块。

## 布局与组件

- 默认主窗为 1120×760，最小尺寸为 360×280。顶部使用品牌、概览／传感器／型号目录导航及刷新／采样／显示设置操作，允许随宽度换行；主内容纵向滚动。
- 页标题下方是设备名称、平台、主板与采样状态。宽屏将其放在标题右侧，窄屏下移。长设备名采用单行省略，悬停可看全名，设备详情保留原始值。
- 概览先显示占满内容宽度的温度与散热面板。面板内部宽度至少为 720 时，CPU／GPU 双读数在左侧，真实温度趋势在右侧，按约 46%／54% 分配宽度，列间距为 28；趋势区高度为 108。更窄时改为读数在上、趋势在下，两组温度在内部宽度不足 280 时继续上下排列。风扇读数始终放在趋势与主读数区域下方。
- 系统电源策略与屏幕亮度位于散热面板下方；主内容宽度至少为 660 时并排，窄屏改为上下排列。不可用项保留简短原因与“查看原因”展开入口，不显示整排不可操作的按钮或滑块。
- 供电与电池、设备识别信息继续向下排布。接口限制、操作范围和技术路径保留在可展开详情中。
- 首页 CPU／GPU 分别显示同类当前最高的有效温度。悬停主读数可查标签、设备与路径；这只是按读数来源分组，不推断物理热管或硬件拓扑。
- 首页最多列出三个风扇读数，内部宽度至少为 520 时并排，更窄时逐项排列；其余读数在传感器页查看。首页风扇标签仅在开头匹配已知的 `mechrevo_ec:` 前缀时将其去掉，悬停仍显示完整原始标签，来源不变。CPU／GPU 名称前的小标记与文字保留 6 的项间距。传感器页的名称与来源允许换行，并可一次展开全部来源，包含设备标识、后端、路径及不可用原因。型号目录只表示官方公开产品条目，不授予控制能力。

## 真实采样与反馈

“自动采样”默认开启，可关闭。启动时立即提交首次只读刷新，此后距上次成功快照至少 3 秒且条件允许时再次提交。已有后台任务、待确认的电源或亮度预览、后台不可用或正在延后关窗时，不自动提交刷新。单个后台任务处理设备读取，重复请求不会堆积。

温度趋势只保存本次进程中的真实采样，每个来源最多保留 120 个点。机器身份由厂商、产品、主板、BIOS 与平台组成，身份变化会清空旧历史；来源按设备 ID、读数 ID、后端、路径和单位隔离。缺失、不可用或非有限读数形成断点，不补零、不补齐历史；不足两次有效采样时显示等待提示。

曲线显示当前所选 CPU／GPU 读数来源各自的历史。当前最高来源变化时，显示新来源已有的采样，不拼接其他来源的数值。曲线横轴使用实际采样时间，颜色与主读数标记对应。

导航选中状态有 200 ms 的过渡，常规控件为 180 ms；后台忙碌时刷新图标旋转，并显示采集状态。关闭“界面过渡动画”会取消这些过渡与旋转，状态文字仍可读。后台任务期间按 80 ms 请求界面重绘；自动采样开启且空闲时按 1 秒请求重绘，这不表示每秒读取硬件。

## 操作与持久化

系统电源策略和屏幕亮度仍按预览、显式应用、后端重新校验、回读及必要恢复的事务流程执行。请求值、驱动报告值与失败／恢复结果分开呈现。切换目标或手动刷新会作废已有计划，应用计划只可使用一次。写入、回读或恢复未结束时，原生关窗请求会延后，事务结束后退出。

标准／紧凑、主题、文字缩放、自动采样和动画偏好保存在 eframe 的系统用户配置目录；操作计划与温度历史不持久化。当前紧凑模式只省去型号目录的“收录说明”，布局仍按可用尺寸调整。

## 当前边界

OEM 性能模式、EC 控制、风扇曲线、MUX、RGB 与水冷控制尚未实现，不能从界面或官方目录推断兼容。风扇读数、声学诊断与实际调速是不同能力；本次界面修改不代表已经完成风扇噪声抑制。Windows 已有交叉编译链接记录，尚无实机硬件写入验收。本轮视觉实现的测试与截图应另外记录，不把既有测试结果直接沿用为本轮通过。
