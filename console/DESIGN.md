# 界面设计

当前实现是原生 Rust / egui 桌面界面，入口见 [desktop.rs](crates/gui/src/desktop.rs) 和 [main.rs](crates/gui/src/main.rs)。产品范围见 [PRODUCT.md](PRODUCT.md)。这里记录已实现的视觉与交互约定，不作为硬件兼容或验收证明。

## 方向与基础值

以石墨背景、暖白文字和清楚的间距建立层级，替换旧的紫青色 Cyber-HUD。用户明确不喜欢蓝色；绿与琥珀只用于温度曲线、采样状态及必要反馈，不添加装饰性发光或虚构运行活动。

| 用途 | 石墨主题 | 浅色主题 |
| --- | --- | --- |
| 页面背景 | `#171818` | `#F1F0E9` |
| 内容面板 | `#1F201F` | `#FAF9F3` |
| 侧栏 | `#131414` | `#E6E7DE` |
| 主文字 | `#F1EFE7` | `#252723` |
| 次要文字 | `#A4A59D` | `#64695B` |
| CPU 曲线／确认反馈 | `#A7C08C` | `#45692C` |
| GPU 曲线／等待反馈 | `#DDBB7C` | `#89641F` |
| 错误反馈 | `#ED9A8C` | `#9A2E22` |

默认使用石墨主题，也可选择浅色或跟随系统。文本使用 egui 比例字体样式：正文与按钮 14、次要文字 12、标题样式 22；页面标题 28，温度主读数 42。没有指定统一的字体名称。

基础项间距为 10×9，按钮内边距 14×9，交互最小高度 36；常规控件圆角 8，内容面板圆角 14。面板内边距通常为 20，窄于 300 时为 16。以上均为逻辑单位，文字缩放范围为 80–160%。颜色与数值以源码为准，修改时同步此表。

## 布局与组件

- 默认主窗为 1120×760，最小尺寸为 360×280，均为逻辑单位。可用区域至少为 920×460 时，显示宽度固定为 184 的侧栏；更小的窗口将概览、传感器、型号目录导航放在内容顶部。
- 主内容纵向滚动。概览内容宽度至少为 720 时，温度与供电信息在左，电源策略与亮度操作在右；不足时改为单列。温度面板内宽不足 320 时，CPU / GPU 主读数也上下排列。
- 概览优先显示当前温度、风扇读数、系统电源策略、屏幕亮度及供电信息。设备识别依据、接口限制和操作范围可展开查看，技术路径保留在详情中。
- 首页 CPU / GPU 分别显示同类当前最高的有效温度。悬停主读数可查标签、设备与路径；这是按读数来源分组的显示，不推断物理热管或硬件拓扑。
- 首页产品长名采用单行省略，悬停显示完整名称，设备详情保留原名。传感器页的名称与来源允许换行，并可一次展开全部来源，包含设备标识、后端、路径及不可用原因。
- 首页最多列出三个风扇读数，其余读数在传感器页查看。型号目录只表示官方公开产品条目，不授予控制能力。

## 真实采样与反馈

“实时采样”默认开启，可关闭。启动时立即提交首次只读刷新，此后距上次成功快照至少 3 秒且条件允许时再次提交。已有后台任务、待确认的电源或亮度预览、后台不可用或正在延后关窗时，不自动提交刷新。单个后台任务处理设备读取，重复请求不会堆积。

温度趋势只保存本次进程中的真实采样，每个来源最多保留 120 个点。机器身份由厂商、产品、主板、BIOS 与平台组成，身份变化会清空旧历史；来源按设备 ID、读数 ID、后端、路径和单位隔离。缺失、不可用或非有限读数形成断点，不补零、不补齐历史；不足两次有效采样时显示等待提示。

曲线显示当前所选 CPU / GPU 读数来源各自的历史。当前最高来源变化时，显示新来源已有的采样，不拼接其他来源的数值。曲线横轴使用实际采样时间，有限的绿与琥珀与主读数标记对应。

选中导航和常规控件的过渡时间为 180 ms；后台忙碌时刷新图标旋转，并显示更新状态。关闭“界面过渡动画”会取消这些过渡与旋转，状态文字仍可读。后台任务期间按 80 ms 请求界面重绘；实时采样开启且空闲时按 1 秒请求重绘，这不表示每秒读取硬件。

## 操作与持久化

系统电源策略和屏幕亮度仍按预览、显式应用、后端重新校验、回读及必要恢复的事务流程执行。请求值、驱动报告值与失败／恢复结果分开呈现。切换目标或手动刷新会作废已有计划，应用计划只可使用一次。写入、回读或恢复未结束时，原生关窗请求会延后，事务结束后退出。

标准／紧凑、主题、文字缩放、实时采样和动画偏好保存在 eframe 的系统用户配置目录；操作计划与温度历史不持久化。当前紧凑模式只省去型号目录的“收录说明”，布局仍按可用尺寸调整。

## 当前边界

OEM 性能模式、EC 控制、风扇曲线、MUX、RGB 与水冷控制尚未实现，不能从界面或官方目录推断兼容。Windows 仅有交叉编译链接证据，未完成实机硬件写入验收；本轮视觉记录也不增加 Linux 的硬件控制验收范围。
