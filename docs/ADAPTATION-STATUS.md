## 本轮新增的协议证据

本机 BIOS 的 `PPFG=4`、GPU 模块标识 `GFID=0x11`，按该 BIOS 的分支选择 `AX44`。
已只读获取该 12 字节缓冲区，并通过 SMRW 的三个 0xbb 读取逐 DWORD 交叉验证。
原厂参数表的身份对应已有新证据，不再只是拿别的型号表猜测。

这仍不等于 Windows 风扇 profile 目录映射完成。Windows 结构体的字段名是线索，
单位、编码、有效范围与完整写入/恢复顺序尚未确认，因此维持当前 55 W RAPL 控制。
